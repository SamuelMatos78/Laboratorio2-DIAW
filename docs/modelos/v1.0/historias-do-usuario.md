# Histórias do usuário — v1.0

1. Como visitante, quero criar uma conta para acessar o sistema.
2. Como usuário cadastrado, quero entrar com usuário e senha para que meus dados e pedidos fiquem protegidos.
3. Como cliente, quero manter RG, CPF, nome, endereço e profissão para apresentar meus dados ao agente.
4. Como cliente, quero manter até três empregadores e rendimentos para instruir a análise financeira.
5. Como cliente, quero criar um pedido de aluguel pela Internet informando automóvel e período desejado.
6. Como cliente, quero consultar a situação do pedido e o parecer para acompanhar a análise.
7. Como cliente, quero alterar um pedido enquanto ele aguarda análise.
8. Como cliente, quero cancelar um pedido que ainda não teve o contrato executado.
9. Como agente de empresa ou banco, quero iniciar a análise e ajustar os dados do pedido durante a revisão.
10. Como agente, quero registrar um parecer financeiro favorável ou desfavorável.
11. Como agente, quero executar o contrato de um pedido aprovado e informar quem será o proprietário do automóvel.
12. Como agente de banco, quero associar um crédito concedido pelo banco ao contrato de aluguel.

## Critérios de aceitação resumidos

- Não é possível acessar pedidos ou cadastro sem login.
- Um cliente consulta e altera somente seus próprios dados e pedidos.
- A quantidade de vínculos empregatícios de um cliente não ultrapassa três.
- Um pedido só segue para execução após parecer favorável.
- Para registrar crédito, devem ser informados o valor e um agente do tipo banco.
- A execução registra proprietário como cliente, empresa ou banco.
