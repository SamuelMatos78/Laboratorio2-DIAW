## Escopo representado

Cadastro e autenticação de clientes e agentes; manutenção do cadastro de cliente e de até três rendimentos; criação, consulta, alteração e cancelamento de pedidos; análise financeira por agentes; encaminhamento para contrato; automóvel com tipo de proprietário; e crédito opcional concedido por banco agente.
